# Telecom-Customer-churn

The Telecom Customer Churn Analysis project focused on identifying customers who are likely to leave a telecom service provider and understanding the factors influencing customer churn. Customer churn is one of the major challenges in the telecom industry because losing existing customers directly affects company revenue and growth.

In this project, telecom customer data containing information such as customer demographics, subscription details, internet services, contract type, monthly charges, total charges, payment methods, and customer support interactions was analyzed using data analytics and machine learning techniques.

The project workflow included:

Data collection and preprocessing
Handling missing values and inconsistent records
Exploratory Data Analysis (EDA)
Feature engineering and encoding categorical variables
Identifying patterns related to customer churn
Building predictive machine learning models

Using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn, detailed visual analysis was performed to discover trends and relationships in the dataset. Key analyses included:

Churn distribution among customers
Contract type vs churn rate
Monthly charges and total charges analysis
Internet service and add-on service impact on churn
Senior citizen and demographic analysis
Payment method and billing preferences
Customer tenure analysis
